# Cognizant Digital Nurture 5.0 – Spring Framework Practice

## Overview

This repository contains my hands-on practice and learning exercises completed as part of the **Cognizant Digital Nurture 5.0** program. It includes examples demonstrating the core concepts of the Spring Framework using Maven and XML-based configuration.

## Concepts Covered

* Spring Core
* Inversion of Control (IoC)
* Dependency Injection (DI)
* Bean Configuration
* Setter Injection
* Constructor Injection
* Component Scanning
* Spring Web MVC (Basics)
* Maven Project Setup
* XML Configuration
* Application Properties
* Database Configuration

## Technologies Used

* Java 8
* Spring Framework
* Maven
* XML Configuration
* Oracle Database
